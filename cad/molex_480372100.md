# Molex 48037-2100 shell model

Source: [`../data/480372100_sd.pdf`](../data/480372100_sd.pdf), drawing
SD-48037-003 revision C. This is a **shell-only visualization model**, made
locally in CadQuery, not manufacturer-supplied MCAD or a manufacturing model.
The plastic housing, locating pegs, contacts and solder tails are omitted,
as requested. The shell's two metal mounting legs are included.

## Drawing dimensions used

| Feature | mm |
|---|---:|
| Shell width | 12.00 |
| Shell length | 18.80 |
| Mating end forward of mounting-hole centerline | 17.80 |
| Shell height, excluding mounting legs | 4.50 |
| Top above solder-tail seating plane / PCB top | 3.10 |
| Overall height including mounting legs | 4.80 |
| Mounting-leg width along insertion direction | 2.00 |
| Mounting-slot center spacing across the connector | 11.70 |

The shell therefore spans footprint X = −6.00…+6.00 mm and
Y = −1.00…+17.80 mm. Its main bottom is at Z = −1.40 mm; the mounting legs
reach Z = −1.70 mm. The drawing's recommended PCB edge is at footprint
Y = +2.75 mm, relative to the mounting-hole centerline.

The 0.30 mm shell gauge, corner radii, rear underside relief, rounded leg
ends, and retention-window dimensions are approximations of undimensioned
drawing features. Stamped spring tongues, seams and embossing are omitted.
Use the manufacturer drawing, not these approximations, for mating-interface
or tooling design.

## KiCad integration

- Footprint: `footprint:connector-USB-A-male-smd-Molex-480372100`.
- Full shell projection: 0.10 mm outline on **Dwgs.User**, including the overhang.
  It is deliberately not printed as silkscreen outside the PCB.
- Existing pads, holes, courtyard and board-edge silk guide were retained.
  This addition is **not** a land-pattern correction or complete land-pattern audit.
- Model: `${KIPRJMOD}/cad/molex_480372100.step`.
- Scale `(1,1,1)`, rotation `(0,0,0)`, offset `(0,0,0)`.
- Origin: midpoint of the two mounting-slot centers at the PCB top surface.
  STEP +X is footprint +X; STEP +Y is **opposite** footprint +Y; STEP +Z is up.
  STEP bounds: X ±6.00, Y −17.80…+1.00, Z −1.70…+3.10 mm.

The project library footprint has this outline and model assignment. Reload
open editor copies or update placed copies to receive library changes.
No external model download is required.

## Regeneration and validation

```sh
./cad/cq cad/molex_480372100.py
```

The script checks for one valid connected solid, checks the 12.00 × 18.80 ×
4.80 mm envelope, exports a colored STEP, and reloads it to verify validity.
A KiCad STEP export of J1 was also checked for model-path resolution, correct
XY registration, outward direction and unit scale.
